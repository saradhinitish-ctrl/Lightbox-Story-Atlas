# The Light Table — Lightbox theme

A lightbox is the lit table where film is laid out to be judged. The app is that table.

| Element | Meaning | Where |
|---|---|---|
| Opal surface with grain, grid and a soft lamp glow | The lit table | Behind every view |
| Graphite chassis with a measuring rule | The table's frame | Header, dock, toasts, Android download |
| White slide mounts with an inner window | Your work laid on the table | Story Foundation prompts, cards, dialogs |
| Frame numbers (`01A`, `02A`…) in red | Edge print on motion-picture film | Foundation prompts, labels, cylinder counter |
| Red grease-pencil circle, underline and tick | A choice marked on a contact sheet | Current workspace, welcome headline, chosen template |
| Tape strips | A sheet held down on the table | Dialogs, the Android card |
| Sprocket strip | A frame on a strip of film | Beat timeline cards |
| Lamp flicker | The table switching on | Opening titles (off for reduced motion) |

## Materials
Generated by `tools/make-light-table-textures.py` (numpy and Pillow) into `assets/textures/`, about 180 KB in total. Every texture tiles seamlessly. Each one is a neutral texture blended over its base colour, so the material shows but the average tone and text contrast stay the same.

| Texture | Material | Blend |
|---|---|---|
| `table-opal.webp` | Opal acrylic diffuser: uneven backlight and clumped grain at several sizes (real film grain clumps; uniform per-pixel noise reads as damage) | soft-light |
| `vellum.webp` | Tracing paper or vellum: cloudy fibre "formation", faint fibres and tooth | soft-light |
| `mount.webp` | White card stock of a slide mount | multiply |
| `chassis.webp` | Graphite powder-coat, brushed along its length | soft-light |
| `tape.webp` | Crepe masking tape | colour |

- **Grease pencil:** wax rather than ink. The line wavers, has a lighter second pass, and skips briefly where the pencil lifts.

## Tokens
Table `#EFEDE7`, mount `#FFFFFF`, ink `#1C1B19`, chassis `#18181A`, grease pencil `#D4301F` (text `#B3261A`). One accent only: red.

## Type
Instrument Serif (titles), DM Sans (interface), DM Mono (edge print and labels), Big Shoulders Display (frame numbers). The first three are the cylinder's own fonts, so the cylinder sits in the theme natively.

## Files
- `light-table.css`: the design. Loaded last.
- `light-table-surfaces.css`: GENERATED. It re-inks the older layers' lime and lavender as grease-pencil red. Rebuild with `(cd export-tools && npm install) && node tools/build-light-table.mjs`.
- `assets/fonts/big-shoulders-display-latin-wght-normal.woff2` (SIL OFL 1.1).

## The Atlas cards
**Superseded:** the Atlas is now a darkroom (`darkroom-atlas.md`). The light table and the cylinder described below are no longer loaded; this section is kept as history.

`light-table-atlas.css` styles them; `story-cylinder-v9.js` (`shape()`) re-lays each card's replica into one skeleton. Text is read from the native React card with `textContent`, so data stays live and nothing is written back.

### Anatomy (shared by all five)
| Slot | Spec |
|---|---|
| Edge | 12px radius, 1px ink hairline at 10%, cotton card stock (`card.webp`), 3px top edge in the card's shade |
| Head | 33px: frame number (Big Shoulders 13px, red) · label (DM Mono 9px, .16em) · ↗, over a hairline with a 22px red tick |
| Title | Instrument Serif, `clamp(36px, 2.75vw, 42px)` / .98, -.035em; 18px below the head |
| Meta | DM Sans 11.5px, muted, one line; 8px below the title |
| Preview | Fills the remaining height (16px above, 12px below) and clips cleanly |
| Foot | 48px on a full-bleed rule; the action in DM Sans 600 12.5px red and a → that leans in on hover |

Spacing runs on 4px steps. Short screens (`.is-compact`, card under 346px) tighten the same skeleton and drop the meta line.

### Depth
The active card lifts 9px with a long ambient shadow (`.lb-cylinder-lift`, opacity-driven). Each step away, a card shrinks by about 4% and a veil in the table's tone (`.lb-cylinder-veil`) rises to 26%, then to 80% for the far pair. Only transform and opacity animate. Reduced motion snaps.

### The desk
The desk (`.lbx-desk`) is aria-hidden and pointer-events:none apart from the slate and the tally:
- **Slate** (top-left): a slug line that reads the hour (`INT. WRITING ROOM — DAWN/DAY/DUSK/NIGHT`). The scene number follows the active card. Click for another take; take 07 is circled, "print it."
- **Tally** (bottom-left, by the arrows): grease-pencil tally marks for the days you've opened the Atlas (`localStorage: lightbox.desk.days`). Hover to read them.
- **Coffee ring** with the script supervisor's note "cont. — cup was full in the wide" (left margin, 1240px and wider)
- **"1 page ≈ 1 minute"**, pencilled in the right margin (1240px and wider)
- **Registration marks** at the sheet's corners, and **DO NOT SCALE** by the last one
- **Edge print** down the right margin: `LBX 0001 ▸ 24 FPS ▸ 180° SHUTTER ▸ 1.85 : 1 ▸ SHEET 01` (1100px and wider)
